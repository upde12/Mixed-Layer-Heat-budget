## 상황 요약
- DOI resolved page/PDF가 CLI에서 403/404 반환

## 에러 메시지
```
AGU/AMS 링크가 봇 차단 또는 세션/쿠키 필요로 403/404 응답
```

## 원인 진단
- Cloudflare/세션 의존·특수문자 DOI 인코딩 문제

## 해결 절차
1. 브라우저/기관 로그인으로 접근, 저장소에는 DOI/랜딩만 안내; 링크 제공 지침 강화

## 예방 및 메모
- 후속 조치 및 참고 링크를 작성하세요.

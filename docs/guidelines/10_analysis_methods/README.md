# 분석 방법 지침(개요)

일반 지침(예: LLM, 시각화)은 상위 번호로 유지하고, 개별 분석 방법은 본 폴더(10_*) 하위에 정리합니다. 각 방법은 요약 가이드(README)와 상세 매뉴얼(manual.md)로 구성합니다.

## 현재 제공 방법
- Heat Budget (혼합층 열수지)
  - 본 레포에서는 개요만 유지합니다. 세부 내용은 MLHB 프로젝트로 이동했습니다.
  - 위치 안내(텍스트): MLHB/docs/heat_budget

추가 분석 방법(예: 에너지 수지, EOF/MCA, 질량 수지 등)은 동일한 구조로 하위 폴더를 추가하세요.
